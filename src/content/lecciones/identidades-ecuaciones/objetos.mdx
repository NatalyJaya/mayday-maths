## Identitat

<Callout tipo="definicion">
	Una **identitat trigonomètrica** és una igualtat que es compleix per a **tots** els valors de la variable per als quals els dos membres estan definits.
</Callout>

Exemples: $\sin^2 x + \cos^2 x = 1$ (per a tot $x$), o $\tan x = \frac{\sin x}{\cos x}$ (per a tot $x$ amb $\cos x \ne 0$).

- Per **demostrar** que una igualtat és una identitat, cal raonar amb fórmules que valguin sempre. Provar amb uns quants valors **no** n’hi ha prou: podria fallar en un altre.
- Per **demostrar que no ho és**, n’hi ha prou amb un sol **contraexemple**: un valor de $x$ en què no es compleix.

<Callout tipo="ojo">
	Comprovar una identitat amb un valor concret (per exemple, $x = 30^\circ$) és una **bona manera de detectar errors**, però no és una demostració.
</Callout>

## Equació trigonomètrica

Una **equació trigonomètrica** és una igualtat amb raons trigonomètriques de la incògnita que només es compleix per a alguns valors. **Resoldre-la** és trobar **tots** aquests valors.

### La solució general

Com que les raons es repeteixen, si trobes una solució, sumant-hi voltes completes n’obtens infinites. Per a les equacions bàsiques, amb $\theta$ l’angle que dona la calculadora:

| Equació | Solucions d’una volta | Solució general ($k$ enter) |
| --- | --- | --- |
| $\sin x = k$ | $\theta$ i $180^\circ - \theta$ | $x = \theta + 360^\circ k$, $\;x = 180^\circ - \theta + 360^\circ k$ |
| $\cos x = k$ | $\theta$ i $360^\circ - \theta$ (o $-\theta$) | $x = \pm\theta + 360^\circ k$ |
| $\tan x = k$ | $\theta$ i $\theta + 180^\circ$ | $x = \theta + 180^\circ k$ |

Casos especials que convé tenir clars:

- Si $|k| > 1$, $\sin x = k$ i $\cos x = k$ **no tenen solució** (la recta no talla la circumferència).
- Si $k = 1$ o $k = -1$, la recta és **tangent** a la circumferència: una sola solució per volta ($\sin x = 1 \Rightarrow x = 90^\circ$; $\cos x = -1 \Rightarrow x = 180^\circ$).
- La tangent pot valer qualsevol nombre, i es repeteix cada $180^\circ$, no cada $360^\circ$.

### Solucions en un interval

Als exercicis (i als teus apunts) gairebé sempre es demanen les solucions a $[0^\circ,\ 360^\circ)$: totes les d’**una volta**. Si a la resposta apareix un angle negatiu (com el $-19{,}47^\circ$ que dona la calculadora per a $\arcsin(-\frac13)$), suma-hi $360^\circ$. Si et demanen les solucions en radiants, l’interval és $[0,\ 2\pi)$.

<Callout tipo="ojo" titulo="Angles múltiples">
	Si la incògnita apareix com $2x$ i vols $x \in [0^\circ,\ 360^\circ)$, l’angle $u = 2x$ recorre $[0^\circ,\ 720^\circ)$: **dues voltes**. Cal buscar les solucions de $u$ en dues voltes i després dividir. Amb $\frac{x}{2}$ passa el contrari: $\frac{x}{2}$ només recorre mitja volta.
</Callout>

## La notació, amb compte

| S’escriu | Vol dir | No confondre amb |
| --- | --- | --- |
| $\sin 2x$ | el sinus de l’angle $2x$ | $2\sin x$ (el doble del sinus de $x$) |
| $\sin^2 x$ | $(\sin x)^2$ | $\sin(x^2)$ |
| $\sin\frac{x}{2}$ | el sinus de la meitat de l’angle | $\frac{\sin x}{2}$ |
| $\cos x + \sin x$ | una suma de dos nombres | $\cos(x + \sin x)$ |

## Les fórmules amb què treballaràs

Aquest és el catàleg complet, tal com apareix al resum dels teus apunts. A l’etapa següent veuràs d’on surt cadascuna: **no les has de memoritzar soltes**, perquè gairebé totes es dedueixen de les dues primeres.

<Formula titulo="Raons d’angles compostos" usala="per expressar raons de α ± β, 2α o α/2 en funció de les raons de α i β" nousar="pensant que el sinus o el cosinus «es reparteixen»">
	| Núm. | Fórmula |
	| --- | --- |
	| (1) | $\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$ |
	| (2) | $\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$ |
	| (3) | $\tan(\alpha + \beta) = \dfrac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$ |
	| (4) | $\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$ |
	| (5) | $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$ |
	| (6) | $\tan(\alpha - \beta) = \dfrac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$ |
	| (7) | $\sin 2\alpha = 2\sin\alpha\cos\alpha$ |
	| (8) | $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$ |
	| (9) | $\tan 2\alpha = \dfrac{2\tan\alpha}{1 - \tan^2\alpha}$ |
	| (10) | $\sin\dfrac{\alpha}{2} = \pm\sqrt{\dfrac{1 - \cos\alpha}{2}}$ |
	| (11) | $\cos\dfrac{\alpha}{2} = \pm\sqrt{\dfrac{1 + \cos\alpha}{2}}$ |
	| (12) | $\tan\dfrac{\alpha}{2} = \pm\sqrt{\dfrac{1 - \cos\alpha}{1 + \cos\alpha}}$ |
</Formula>
