## Identidad

<Callout tipo="definicion">
	Una **identidad trigonométrica** es una igualdad que se cumple para **todos** los valores de la variable para los que los dos miembros están definidos.
</Callout>

Ejemplos: $\sin^2 x + \cos^2 x = 1$ (para todo $x$), o $\tan x = \frac{\sin x}{\cos x}$ (para todo $x$ con $\cos x \ne 0$).

- Para **demostrar** que una igualdad es una identidad, hay que razonar con fórmulas que valgan siempre. Probar con unos cuantos valores **no** basta: podría fallar en otro.
- Para **demostrar que no lo es**, basta un solo **contraejemplo**: un valor de $x$ en el que no se cumple.

<Callout tipo="ojo">
	Comprobar una identidad con un valor concreto (por ejemplo, $x = 30^\circ$) es una **buena forma de detectar errores**, pero no es una demostración.
</Callout>

## Ecuación trigonométrica

Una **ecuación trigonométrica** es una igualdad con razones trigonométricas de la incógnita que solo se cumple para algunos valores. **Resolverla** es encontrar **todos** esos valores.

### La solución general

Como las razones se repiten, si encuentras una solución, sumándole vueltas completas obtienes infinitas. Para las ecuaciones básicas, con $\theta$ el ángulo que da la calculadora:

| Ecuación | Soluciones de una vuelta | Solución general ($k$ entero) |
| --- | --- | --- |
| $\sin x = k$ | $\theta$ y $180^\circ - \theta$ | $x = \theta + 360^\circ k$, $\;x = 180^\circ - \theta + 360^\circ k$ |
| $\cos x = k$ | $\theta$ y $360^\circ - \theta$ (o $-\theta$) | $x = \pm\theta + 360^\circ k$ |
| $\tan x = k$ | $\theta$ y $\theta + 180^\circ$ | $x = \theta + 180^\circ k$ |

Casos especiales que conviene tener claros:

- Si $|k| > 1$, $\sin x = k$ y $\cos x = k$ **no tienen solución** (la recta no corta la circunferencia).
- Si $k = 1$ o $k = -1$, la recta es **tangente** a la circunferencia: una sola solución por vuelta ($\sin x = 1 \Rightarrow x = 90^\circ$; $\cos x = -1 \Rightarrow x = 180^\circ$).
- La tangente puede valer cualquier número, y se repite cada $180^\circ$, no cada $360^\circ$.

### Soluciones en un intervalo

En los ejercicios (y en tus apuntes) casi siempre se piden las soluciones en $[0^\circ,\ 360^\circ)$: todas las de **una vuelta**. Si en la respuesta aparece un ángulo negativo (como el $-19{,}47^\circ$ que da la calculadora para $\arcsin(-\frac13)$), súmale $360^\circ$. Si te piden las soluciones en radianes, el intervalo es $[0,\ 2\pi)$.

<Callout tipo="ojo" titulo="Ángulos múltiples">
	Si la incógnita aparece como $2x$ y quieres $x \in [0^\circ,\ 360^\circ)$, el ángulo $u = 2x$ recorre $[0^\circ,\ 720^\circ)$: **dos vueltas**. Hay que buscar las soluciones de $u$ en dos vueltas y después dividir. Con $\frac{x}{2}$ pasa lo contrario: $\frac{x}{2}$ solo recorre media vuelta.
</Callout>

## La notación, con cuidado

| Se escribe | Significa | No confundir con |
| --- | --- | --- |
| $\sin 2x$ | el seno del ángulo $2x$ | $2\sin x$ (el doble del seno de $x$) |
| $\sin^2 x$ | $(\sin x)^2$ | $\sin(x^2)$ |
| $\sin\frac{x}{2}$ | el seno de la mitad del ángulo | $\frac{\sin x}{2}$ |
| $\cos x + \sin x$ | una suma de dos números | $\cos(x + \sin x)$ |

## Las fórmulas con las que vas a trabajar

Este es el catálogo completo, tal como aparece en el resumen de tus apuntes. En la etapa siguiente verás de dónde sale cada una: **no tienes que memorizarlas sueltas**, porque casi todas se deducen de las dos primeras.

<Formula titulo="Razones de ángulos compuestos" usala="para expresar razones de α ± β, 2α o α/2 en función de las razones de α y β" nousar="pensando que el seno o el coseno «se reparten»">
	| Nº | Fórmula |
	| --- | --- |
	| (1) | $\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$ |
	| (2) | $\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$ |
	| (3) | $\tan(\alpha + \beta) = \dfrac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$ |
	| (4) | $\sin(\alpha - \beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta$ |
	| (5) | $\cos(\alpha - \beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta$ |
	| (6) | $\tan(\alpha - \beta) = \dfrac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$ |
	| (7) | $\sin 2\alpha = 2\sin\alpha\cos\alpha$ |
	| (8) | $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$ |
	| (9) | $\tan 2\alpha = \dfrac{2\tan\alpha}{1 - \tan^2\alpha}$ |
	| (10) | $\sin\dfrac{\alpha}{2} = \pm\sqrt{\dfrac{1 - \cos\alpha}{2}}$ |
	| (11) | $\cos\dfrac{\alpha}{2} = \pm\sqrt{\dfrac{1 + \cos\alpha}{2}}$ |
	| (12) | $\tan\dfrac{\alpha}{2} = \pm\sqrt{\dfrac{1 - \cos\alpha}{1 + \cos\alpha}}$ |
</Formula>
